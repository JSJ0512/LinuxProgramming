- 셸은 사용자와 리눅스 커널 사이에서 명령어를 전달하는 인터페이스이고 커널은 CPU나 메모리같은 하드웨어를 관리하며 명령어를 실행하고 프로세스를 관리하는 운영체제의 핵심이다

- 사용자의 현재 홈 디렉터리를 의미하는 특수 표기이다

- sh는 유닉스의 기본 셸이고 bash는 sh와 호완성을 가진 여러 셸의 장점을 결합한 셸이고 zsh는 bash의 기능에 다양한 기능을 제공한다

- 실행할 여러 개의 명령어를 기술한 파일이며 명령어를 하나씩 직접입력 하는 대화형 방식이다
