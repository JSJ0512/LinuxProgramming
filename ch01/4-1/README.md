- 다렉터리 : 여러개의 파일을 모아 놓은 파일
- 서브 디렉터리 : 디렉터리 안에 포암되어 있는 디렉터리
- 작업 디렉터리 : 현재 위치하여 작업하는 디렉터리
- 홈 디렉터리 : 사용자별로 할당되는 개인용 디렉터리
- ~ : 홈 디렉터리를 나타내는 기호 
- . : 현재 작업 디렉터리를 의미하는 기호 
- .. : 부모 디렉터리를 의미하는 기호
- / : 루트디렉터를 의미함
- 상대경로 : 현재 작업 디렉터리를 기준으로 표기함
- 절대경로 : 해당 파일위치를 명확하게 나타냄
---------------------------------------------------------------------------------------------------------------------------------

- / (절대경로)
- ../ (상대경로)
- cd /usr/lib/gcc/x86_64-linux-gnu ( 앞에 / 를 붙여 절대경로 이동함)
- cd usr/lib/gcc/x86_64-linux-gnu ( 앞에 / 를 붙이지 않고 상대경로 이동함)
